# 🧩 Maze Game

Juego de laberinto desarrollado en Unity. Este proyecto utiliza **Git LFS (Large File Storage)** para manejar assets pesados como texturas, modelos 3D y escenas.

---

## 🚀 Clonar el repositorio

### 🔑 Requisitos previos
- [Git](https://git-scm.com/downloads)
- [Git LFS](https://git-lfs.github.com/)
- Cuenta de GitHub con llave SSH configurada (recomendado)

### 📥 Clonar con SSH
Recomendado si tienes una llave SSH:
```bash
git clone git@github.com:jcaritam/maze-game.git
